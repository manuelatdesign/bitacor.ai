# Plan first

Usar en tareas de producto, UX o flujo. Ver `contexto/roles-y-calidad.md`.

## Pasos
1. Reformular el objetivo en 1–2 frases.
2. Listar **2–3 caminos** (esfuerzo / riesgo / fidelidad al design).
3. Marcar **recomendado** + por qué (≤3 líneas).
4. Si falta info crítica: máximo **1–2** preguntas bloqueantes.
5. **Parar** hasta confirmación (“ok”, “ve con el recomendado”, camino N).
6. Tras confirmación: implementar solo lo acordado. Al cerrar, actualizar `state/` si cambió el producto.

## Excepción (no esperar)
Usuario dice “implementa X directamente”, “hazlo ya”, o “Implement the plan as specified…”.

## No hacer
- No tocar estilo gráfico sin pedido explícito.
- No asumir prefs/flujo no dichos; preguntar o documentar la asunción.
- No volcar planes de 2 páginas; densidad > narrativa.
